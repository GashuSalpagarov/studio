# 00. Обзор и концепт

## TL;DR
Промо-сайт студии разработки, построенный вокруг метафоры **«бесконечная лента пути»**. Главная страница — пять смыслово-связанных блоков, каждому из которых соответствует своя анимационная сцена единой чёрной линии (путь). Между концом и началом — инверсивный анимационный мост (CTA), скролл бесконечный. Внутренние страницы — продуктовые, белые, без инверсии и без сложных WebGL-сцен. Десктоп — полноценный WebGL по линии; мобильный — упрощённая плоская версия с сохранением loop и инверсии (SVG-линия + GSAP, без Three.js).

## Бизнес-цель
Сайт = витрина студии. Он должен:
- Доказывать инженерные/визуальные компетенции студии самим фактом своего существования.
- Удерживать внимание потенциального заказчика на всём протяжении скролла главной.
- Завершаться чёткой точкой контакта (CTA + страница «Контакты» с формой).
- Поддерживать рост в каталог услуг и кейсов через детальные страницы.

## Главная страница: 5 блоков ↔ 5 сцен линии

Главная — одна непрерывная сцена «линии», поделённая на пять смысловых сегментов. Сцены 1:1 соответствуют DOM-блокам.

| Блок | Сцена линии | Смысл |
|---|---|---|
| Hero | Точка | Стартовая статика → линия рождается из точки |
| Услуги | Инструменты | Линия проходит сквозь набор «инструментов» (метафора 6 направлений) |
| Портфолио | Продукты | Линия движется через «продукты» — точки-кейсы |
| Подход | Парный путь | Линия раздваивается, клиент идёт рядом со студией |
| CTA | Замыкание + инверсия | Линия замыкается, мост между концом и началом |

После CTA пользователь продолжает скроллить и плавно возвращается на Hero — **бесконечный скролл**, не одноразовый возврат.

Подробная разбивка прогресса 0..1 — в [03-scroll-scenario.md](./03-scroll-scenario.md).

## Multi-page структура

Главная — нарративная, с линией и инверсией. Все остальные страницы — продуктовый стиль (белый фон, без инверсии, без тяжёлого WebGL).

Запланированные роуты:

| Роут | Назначение |
|---|---|
| `/` | Главная: 5 блоков + сцена линии + CTA-мост |
| `/services` | Все услуги (каталог 6 направлений) |
| `/services/[slug]` | Детальная страница услуги (×6) |
| `/cases` | Все кейсы (каталог) |
| `/cases/[slug]` | Детальная страница кейса (4–6 топовых) |
| `/approach` | Развёрнутый «Подход» |
| `/contact` | Контакты + форма обратной связи |

Внутренние страницы — белые, продуктовые. Лёгкие DOM-анимации допустимы; сцена-линия там не живёт. GlobalCanvas в layout остаётся, но на детальных страницах либо отключается, либо используется минимально.

## Per-scene route transitions

Клик на услугу или кейс из разных блоков главной запускает **разные анимации перехода**: каждая сцена «впадает» во внутреннюю страницу по-своему (например, из «Инструментов» — иначе, чем из «Продуктов»). Конкретные паттерны фиксируются на этапе визуального дизайна; здесь требование зафиксировано как обязательное.

## Жёсткие ограничения

- **Главный визуальный объект — чёрная линия (путь).** Не wormhole-туннель. Туннельные эффекты допустимы как один из приёмов wipe-перехода между сценами или блоками, но не как центральная метафора. Камера — преимущественно ortho или плоская перспектива вдоль линии.
- **Чёрно-белый минимализм**, единая стилистика на всех страницах. Цветные акценты — только если позже подтвердятся в визуальном дизайне.
- **CTA = инверсивный анимационный мост.** Wipe-переход white↔black именно на CTA-зоне. Инверсия живёт только на главной; на детальных страницах её нет.
- **Бесконечный скролл (loop) — обязателен** на главной, не как «опция возврата».
- **Mobile — упрощённая плоская версия**, не «WebGL off + статичный poster». На мобиле работают Lenis, GSAP+ScrollTrigger, SVG-линия (`stroke-dashoffset`), CSS-инверсия и infinite loop. Отключается или заменяется упрощённой 2D-сценой только Three.js. Триггеры и `prefers-reduced-motion` — см. [05-performance.md](./05-performance.md).
- **Кольцо прогресса** в углу — простое (заполняющийся stroke по scroll-progress), без чисел и сегментов.
- **GSAP — основа таймлайнов и ScrollTrigger.**
- **Lenis** (`lenis/react`) — единственный источник плавного скролла.
- **Сайт = единый GlobalCanvas** через всё приложение; на главной — активная сцена линии, на внутренних — отключение или минимум.
- **Нет кастомных физических симуляций**, тяжёлых WASM-расчётов, видеотекстур больше нескольких МБ.

## Открытые вопросы (дизайн-этап)

Зафиксировано как «решается на этапе визуального дизайна», не блокирует реализацию текущего этапа:

- **Эволюция фона** как «рождение чертежа» (от чистого листа к разметке). Сейчас — пустой белый/чёрный фон.
- **Фильтры портфолио** (услуга / индустрия / тип клиента) — детали реализации позже.
- **6 направлений услуг** — конкретный контент студии не известен; используются placeholder-имена.
- **4–6 топовых кейсов** — контент не известен; placeholder.
- **Имя студии, заголовки, копирайт** — placeholder.
- **Поведение wipe-перехода:** «круги» в формулировке пользователя — это сам infinite-scroll, а не отдельные маркеры на странице.
- **Per-scene route transitions:** конкретные паттерны (по сцене) — позже.
