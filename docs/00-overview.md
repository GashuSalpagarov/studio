# 00. Обзор и концепт

## TL;DR
Одностраничный промо-сайт студии разработки, построенный вокруг единой 3D-сцены, которая разворачивается по мере скролла: от статичного hero — через сжатие в точку, полёт по spline и серию wormhole-сегментов — к финальной информационной секции и зацикливанию с инвертированными цветами. Десктоп — полноценный WebGL, мобильный — статичный fallback.

## Бизнес-цель
Сайт = витрина студии. Он должен:
- Доказывать инженерные/визуальные компетенции студии самим фактом своего существования.
- Удерживать внимание потенциального заказчика на всём протяжении скролла.
- Завершаться чёткой точкой контакта (CTA, контакты).
- Открывать возможность для расширения в case studies (см. [01-stack.md](./01-stack.md), раздел про выбор Next.js).

## Сценарий (нарратив скролла)
Сайт читается как одна непрерывная сцена с протагонистом-точкой:

1. **Hero (статика).** Первый экран — заголовок и базовая композиция, без анимации.
2. **Compress to dot.** Hero сжимается в точку через FLIP-переход; в конце DOM-точка совпадает по координатам с WebGL-точкой и происходит swap.
3. **Travel along line.** Точка летит по сплайну (`CatmullRomCurve3`); камера движется рядом.
4. **Wormhole 1 → Stage 1.** Влёт в туннель и выход в первую сцену-этап разработки студии.
5. **Wormhole 2..N → Stage 2..N.** Каждая стадия (Discover / Design / Build / …) — отдельный сегмент сцены, разделённый туннелями.
6. **Information base.** Финальный экран: контакты, CTA, плотный DOM поверх замедляющейся сцены.
7. **Inversion loop.** При продолжении скролла цвета инвертируются и сцена возвращается в начало.

Подробная разбивка прогресса 0..1 — в [03-scroll-scenario.md](./03-scroll-scenario.md).

## Жёсткие ограничения
- **3D только на десктопе.** Мобильная версия — статичные постеры + CSS-анимация, без WebGL. Триггеры детекта — в [05-performance.md](./05-performance.md).
- **GSAP — основа таймлайнов и ScrollTrigger.**
- **Lenis** (`lenis/react`) — единственный источник плавного скролла.
- **Сайт = одна общая 3D-сцена.** Один fixed canvas через всю страницу; прогресс скролла переключает сегменты сцены, камера летит по spline.
- **Нет кастомных физических симуляций**, тяжёлых WASM-расчётов, видеотекстур больше нескольких МБ — всё ради бюджета FPS и веса.
